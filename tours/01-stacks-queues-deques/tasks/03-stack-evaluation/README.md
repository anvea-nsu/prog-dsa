# Task 3. Evaluation Using a Stack

Programming, Assignment 2.1 — Stacks, Queues and Deques

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Evaluate the given expression in reverse Polish notation.

## Input

The input file contains a single line with an expression in reverse Polish notation. The operands are integers. Spaces separate the numbers and operators. The line is at most $2{,}000$ characters long.

## Output

Write one integer, the value of the expression. Division by zero is guaranteed never to occur.

## Example

**Input**

```text
12 5 + 7 - 2 10 * -
```

**Output**

```text
-10
```
