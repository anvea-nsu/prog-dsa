# Task 2. Heapsort

Programming, Assignment 2.2 — Heaps

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 2 seconds |
| Memory limit | Reasonable |

Sort the given sequence of integers using your own implementation of heapsort.

## Input

The first line contains the sequence length $N$ ($1\le N\le10^6$). The next line contains $N$ space-separated integers with absolute values at most $10^6$.

## Output

Print the sorted sequence on one line, separating the numbers with spaces.

## Example

**Input**

```text
5
12 5 1 -3 4
```

**Output**

```text
-3 1 4 5 12
```
