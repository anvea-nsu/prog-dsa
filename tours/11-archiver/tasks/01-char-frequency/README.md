# Task 1. Character Frequencies

Programming, Assignment 12 — Archiver

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Count how many times each character occurs in a text file.

## Input

The file contains nonempty text and is at most 2.1 MB in size.

## Output

For each character present, print one line in the format `a : b`, where $a$ is its decimal character code and $b$ is its positive occurrence count. List the characters in increasing order of code.

## Example

**Input**

```text
кол около колокола
```

**Output**

```text
10 : 1
32 : 2
224 : 1
234 : 4
235 : 4
238 : 7
```
