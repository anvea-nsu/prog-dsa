# Task 4. Counting Nodes at a Given Level

Fundamentals of Programming, Assignment 14 — Trees

| Field | Value |
| --- | --- |
| Source | Core |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Build a binary search tree from the sequence of integers, skipping duplicates. Count the nodes at the specified level.

## Input

The first line gives the level, a nonnegative integer at most $1{,}000$. The next line contains at most $1{,}000$ space-separated integers to insert.

## Output

Print the number of nodes at the specified level.

## Example

**Input**

```text
1
5 1 10 -3 12 1 9 4
```

**Output**

```text
2
```
