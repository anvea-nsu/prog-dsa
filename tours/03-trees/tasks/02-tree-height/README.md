# Task 2. Tree Height

Fundamentals of Programming, Assignment 14 — Trees

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Build a binary search tree by inserting the given integers in order. Skip duplicates. Determine the height of the resulting tree.

## Input

Read at most $1{,}000$ space-separated integers.

## Output

Print one integer, the height of the tree.

## Example

**Input**

```text
5 1 10 -3 12 1 9 4
```

**Output**

```text
2
```
