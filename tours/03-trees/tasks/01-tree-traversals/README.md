# Task 1. Tree Traversals

Fundamentals of Programming, Assignment 14 — Trees

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Build a binary search tree by inserting the given integers in order. Skip duplicate values. Traverse the resulting tree in preorder and postorder.

## Input

Read at most $1{,}000$ space-separated integers.

## Output

Print the preorder traversal on the first line and the postorder traversal on the second. Separate values with spaces.

## Example

**Input**

```text
5 1 10 -3 12 1 9 4
```

**Output**

```text
5 1 -3 4 10 9 12
-3 4 1 9 12 10 5
```
