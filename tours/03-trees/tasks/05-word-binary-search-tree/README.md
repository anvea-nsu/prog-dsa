# Task 5. A Binary Search Tree of Words

Fundamentals of Programming, Assignment 14 — Trees

| Field | Value |
| --- | --- |
| Source | Core |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Build a binary search tree from the given words, skipping duplicates, and traverse it in inorder.

## Input

The file contains one word per line, with no empty lines. There are at most $1{,}000$ words, each at most $100$ characters long.

The source also mentions a following line of at most $1{,}000$ space-separated integers. Its purpose is unspecified, and the example contains only words.

## Output

Print the words in lexicographic order, one per line.

## Example

**Input**

```text
orange
mallon
apple
grapes
plum
banana
```

**Output**

```text
apple
banana
grapes
mallon
orange
plum
```
