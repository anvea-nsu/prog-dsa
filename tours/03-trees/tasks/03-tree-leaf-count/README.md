# Task 3. Counting Leaves

Fundamentals of Programming, Assignment 14 — Trees

| Field | Value |
| --- | --- |
| Source | Basic |
| Input file | `input.txt` |
| Output file | `output.txt` |
| Time limit | 1 second |
| Memory limit | Reasonable |

Build a binary search tree from the given sequence of integers, skipping duplicates. Count the leaves, that is, nodes with no children.

## Input

Read at most $1{,}000$ space-separated integers.

## Output

Print one integer, the number of leaves.

## Example

**Input**

```text
5 1 10 -3 12 1 9 4
```

**Output**

```text
4
```
